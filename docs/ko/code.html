소스 코드

저장소의 Python 소스와 설정, 테스트를 여기서 바로 읽을 수 있다. 왼쪽 목록이나 아래 모듈 지도에서 파일을 고르면 된다. 줄 번호를 누르면 그 줄로 바로 가는 링크가 생긴다.

빠른 시작

pip install -e ".[dev]"                 # core + pytest
pip install -e ".[rl]"                  # + torch / crafter
pip install -e ".[jax]"                 # + jax / craftax

python main.py                                          # planner on all base tasks
python train_ppo.py ppo.total_steps=1000000             # PPO + MoE on Crafter
python train_diffusion.py demos.policy_checkpoint=runs/ppo/checkpoint.pt
python evaluate_policy.py policy=runs/diffusion/checkpoint.pt episodes=50
python train_craftax.py                                 # Craftax PPO, 1e9 steps
python train_craftax.py algo.rnn=true                   # Craftax PPO-RNN
pytest -q                                               # test suite

모듈 지도

세 갈래(계획, Crafter 정책, Craftax 학습)에서 중심이 되는 파일들이다. 이름을 누르면 아래 뷰어에 열린다.

파일역할
diffu_moe_vlm/core.py테크 트리(레시피·도구), 태스크, 계획 파싱
diffu_moe_vlm/env.py기호 테크 트리 환경 (Gymnasium API)
diffu_moe_vlm/planner.pyLLM 플래너, 규칙 기반 폴백, 재계획
diffu_moe_vlm/selector.py하위 목표 선택 (계획 순서·우선순위·의존성·horizon)
diffu_moe_vlm/controller.py목표 조건부 컨트롤러, 매크로 행동 생성
diffu_moe_vlm/evaluator.pyDescribe, Explain, Plan and Select 평가 루프
diffu_moe_vlm/crafter_env.pyCrafter 래퍼, 업적 성공률과 Crafter 점수
diffu_moe_vlm/nn/moe.pyTop-k 노이즈 게이트 MoE와 load-balancing loss
diffu_moe_vlm/nn/diffusion.pyaction chunk Diffusion 정책 (x0 예측, DDIM)
diffu_moe_vlm/nn/encoders.py시각 인코더: CNN, ViT, 사전학습 CLIP/SigLIP
diffu_moe_vlm/imu.py3D 궤적·IMU 데이터 형식과 합성 데이터 생성기
diffu_moe_vlm/rl/ppo.pyGAE, MoE 보조 손실, ICM이 들어간 PPO (PyTorch)
diffu_moe_vlm/rl/diffusion_bc.pyPPO demonstration으로 하는 Diffusion 모방학습
diffu_moe_vlm/jax_rl/ppo.pyjax.jit 하나로 도는 PPO·PPO-RNN, 체크포인트와 재개
diffu_moe_vlm/jax_rl/wrappers.py배치 Craftax, optimistic reset, 에피소드 로깅
train_ppo.pyCrafter에서 PPO + MoE 학습
train_diffusion.pyDiffusion 정책 모방학습
evaluate_policy.py정책 평가 (업적, Crafter 점수)
train_craftax.pyCraftax 학습 진입점 (청크 단위, 재개 가능)
compare_craftax_run.py실행 결과를 레퍼런스 W&B 범위와 맞대 보기
run_icm_ablation.pyICM 정규화 실험: GPU 프리셋과 CPU 디버그 프리셋
analyze_icm_ablation.pyICM 실험 보고서: 보너스가 억눌리는지, 탐험이 늘어나는지
tests/test_jax_rl.pyJAX 경로의 GAE·결정론·재개 테스트

코드 보기

스냅샷은 python tools/build_code_snapshot.py로 다시 만든다.

이 페이지에 나오는 약어 15개 풀이
약어풀이뜻
LLMLarge Language Model글을 생성하는 대규모 언어 모델. 여기서는 계획을 쓴다.
VLMVision-Language Model이미지와 글을 함께 다루는 모델. 프로젝트 이름에 들어 있는 원래 목표.
PPOProximal Policy Optimization업데이트 폭을 잘라 새 정책이 옛 정책에서 멀어지지 않게 하는 강화학습 알고리즘.
PPO-RNNPPO with a Recurrent Neural Network정책에 GRU 기억을 넣은 PPO.
GAEGeneralized Advantage Estimation여러 스텝의 TD 오차를 섞어 advantage를 추정하는 방법.
MoEMixture of Expertsexpert 네트워크 여러 개 중 게이트가 입력마다 고른 몇 개의 출력만 섞는 구조.
ICMIntrinsic Curiosity Module다음 상태를 예측하고, 틀린 만큼 호기심 보너스를 주는 모듈.
DDIMDenoising Diffusion Implicit ModelDDPM을 훨씬 적은 단계로 샘플링하는 방법.
CNNConvolutional Neural Network합성곱으로 이미지를 읽는 신경망.
ViTVision Transformer이미지를 패치로 잘라 트랜스포머로 읽는 모델.
CLIPContrastive Language-Image Pre-training짝이 맞는 이미지와 글이 가까워지도록 사전학습한 인코더.
SigLIPSigmoid Loss for Language-Image Pre-trainingCLIP의 손실을 sigmoid로 바꾼 변형.
jitjust-in-time compilation처음 호출할 때 함수를 컴파일해 두고 그 뒤로는 컴파일된 코드로 돌린다.
IMUInertial Measurement Unit가속도와 각속도를 재는 센서.
W&BWeights & Biases학습 지표를 기록하고 그래프로 보여 주는 서비스.
