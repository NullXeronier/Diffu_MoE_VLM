Source code

Read the repository's Python sources, configs and tests right on this page. Pick a file from the list or the module map below; clicking a line number gives a link to that line.

Quick start

pip install -e ".[dev]"                 # core + pytest
pip install -e ".[rl]"                  # + torch / crafter
pip install -e ".[jax]"                 # + jax / craftax

python main.py                                          # planner on all base tasks
python train_ppo.py ppo.total_steps=1000000             # PPO + MoE on Crafter
python train_diffusion.py demos.policy_checkpoint=runs/ppo/checkpoint.pt
python evaluate_policy.py policy=runs/diffusion/checkpoint.pt episodes=50
python train_craftax.py                                 # Craftax PPO, 1e9 steps
python train_craftax.py algo.rnn=true                   # Craftax PPO-RNN
pytest -q                                               # test suite

Abbreviations on this page (15)
Abbr.Stands forMeaning
LLMLarge Language ModelLarge text-generating model; here it writes plans.
VLMVision-Language ModelModel that takes both images and text; part of the project's name and original goal.
PPOProximal Policy OptimizationRL algorithm that clips each update to keep the new policy close to the old one.
PPO-RNNPPO with a Recurrent Neural NetworkPPO whose policy has GRU memory.
GAEGeneralized Advantage EstimationEstimates the advantage by mixing TD errors over several steps.
MoEMixture of ExpertsSeveral expert networks; a gate picks a few per input and mixes their outputs.
ICMIntrinsic Curiosity ModulePredicts the next state and pays a curiosity bonus for how wrong the prediction was.
DDIMDenoising Diffusion Implicit ModelWay to sample a DDPM in far fewer steps.
CNNConvolutional Neural NetworkNetwork that reads images with convolutions.
ViTVision TransformerTransformer that reads an image as a sequence of patches.
CLIPContrastive Language-Image Pre-trainingImage and text encoders pre-trained to agree on matching pairs.
SigLIPSigmoid Loss for Language-Image Pre-trainingCLIP variant trained with a sigmoid loss.
jitjust-in-time compilationCompile a function on its first call, then run the compiled code.
IMUInertial Measurement UnitSensor that measures acceleration and rotation rate.
W&BWeights & BiasesService for logging and plotting training metrics.
