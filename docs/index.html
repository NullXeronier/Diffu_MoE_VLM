Overview

The project has three tracks that share one repository and one evaluation vocabulary (tasks, achievements, success rates). Each track was built to be testable on a laptop-class CPU, with GPU scale-up as configuration only.

What was built

Track A

DEPS on a working world

The original environment returned random pixels and ignored actions, so no task could succeed. A symbolic tech-tree env, a recipe-aware controller, quantity-aware plans and event-based sub-goal completion turn the planner loop into something measurable.

Track B

MoE + diffusion on Crafter

PPO with a CNN encoder and a top-k MoE trunk, plus a diffusion policy that clones PPO action chunks with receding-horizon execution. Switching the denoiser to clean-sample prediction fixed observation-conditioning for one-hot actions.

Track C

Reproducible Craftax

PureJaxRL-style PPO and PPO-RNN with optimistic resets, an ICM bonus normalised by its running mean, and full-state checkpoints. The same command resumes a preempted run with identical results.

Reading the reference runs

!
Why the first Crafter run looked far behind. The reference charts are Craftax-Symbolic (symbolic observations, ~65 achievements) at 1e9 steps on a GPU; the first local run was Crafter pixels at 1e5 steps on a CPU: a different environment and 10,000× less data. The x-axis "Step" in the charts counts PPO updates, not environment steps.
i
Why the ICM run collapsed. Its curiosity bonus grew to ~7.5 per step while the extrinsic reward stayed ~0, so the agent optimised novelty only. The JAX trainer divides the bonus by its running mean and scales it by 0.01. Dividing by the standard deviation is not enough, because a squared prediction error is mostly mean.

Embodied signal: 3D trajectories

A transformer encoder embeds multi-joint 3D trajectories (hands and head) with velocities and a continuous-time embedding of irregular timestamps. It plugs into the MoE policy as an optional input; on synthetic motions it separates four activity classes with >90% accuracy after 150 steps.

Data format: positions (N,T,J,3), timestamps (N,T), optional mask and labels.

Next steps

  • Run the 1e9-step Craftax comparison on a GPU (3–4 hours per run) and check it with compare_craftax_run.py over 2–3 seeds.
  • Port the diffusion policy to the JAX path and evaluate MoE vs. dense trunks at scale.
  • Use the learned policies as low-level skills under the DEPS planner.
  • Connect real IMU recordings in the trajectory format.
